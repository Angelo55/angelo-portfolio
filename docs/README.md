# Portfolio project memory

This directory is the persistent source of truth for the portfolio project. Update it after every approved direction or major development session.

## Files

- `architecture.md`  stack, boundaries, data model, and architecture decisions.
- `design-system.md`  approved visual language, components, motion, and responsive behavior.
- `project-state.md`  current implementation state, completed work, pending tasks, known issues, and next continuation point.
- `change-log.md`  chronological record of approved and implemented changes.

## Maintenance rule

When work changes architecture, visible design, navigation, content structure, integrations, configuration, or development status, update the relevant document and append a dated entry to `change-log.md`.

## Local launch

Double-click Start Portfolio.bat from File Explorer. It opens this folder in VS Code, starts the development server without requiring global CLI commands, and opens http://localhost:3000. Double-click Stop Portfolio.bat when finished.
